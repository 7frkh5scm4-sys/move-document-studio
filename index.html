Move Document Studio

Version 4.0 · PDF artwork pages · Reformatted text as PDF or EPUB · Works offline

Files are processed on this device and are never uploaded. No internet connection is needed. RTF limit: 150 MB per file; PDF/DOCX: 40 MB per file. These are admission limits, not tested device capacities.

Artwork sizing scales text and graphics together, not individual fonts. Larger makes horizontal tiles to avoid cutting off side content. Output is PDF only, because EPUB cannot reflow page artwork.

Manual trim applies first. Automatic trim may miss faint content; disable it if needed.

EPUB output is text plus supported RTF PNG/JPEG pictures. Text size, font, margins, and spacing are chosen on the device. PDF paragraphs are detected automatically, so headings, tables, columns, and running headers or page numbers may appear as ordinary paragraphs. All characters are kept, including those PDF output replaces.

Images are retained only for supported RTF pictures, not PDF/DOCX pictures. RTF picture order follows the source stream; wrapping and caption grouping are not retained.

Prototype: keep originals and verify output. No OCR. PDF artwork reconstruction omits annotations and interactive features; rotated sources are unsupported. Artwork splits can cross lines/tables. RTF parsing is basic: WMF/EMF, binary/linked pictures, and embedded objects unsupported. PDF text output covers standard Latin characters only; unsupported characters are replaced. Large batches can exhaust memory, especially during ZIP creation. This release has not been run in Safari.
