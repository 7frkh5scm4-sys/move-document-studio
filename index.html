Move Document Studio

Version 3.3 · Batch ZIP download · RTF images

Files are processed locally in your browser. Internet loads the third-party libraries. RTF: 150 MB per file; PDF/DOCX: 40 MB per file. These are admission limits, not tested device capacities.

Automatic trim may miss faint content; disable it if needed. Manual trim applies first.

Pictures retain source-stream order and fit pages without stretching. Original tables, wrapping, rich formatting, and caption grouping are not preserved. DOCX/PDF reformatting is text-only.

Prototype: keep originals and verify results. No OCR. PDF reconstruction omits interactive features and annotations, and does not support rotated pages. Splits can cross lines/tables. Basic RTF support: WMF/EMF, binary/linked pictures and embedded objects unsupported. Unsupported characters are replaced. Large batches, especially with images, may exhaust memory. ZIP generation retains output in memory; use smaller batches if it fails. This release has not been run in Safari.
