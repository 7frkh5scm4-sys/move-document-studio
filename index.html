Move Document Studio

Version 3.5 · Single-column text reflow · Batch ZIP · RTF images

Files are processed locally in your browser. Internet loads third-party libraries. RTF limit: 150 MB per file; PDF/DOCX: 40 MB per file. These are admission limits, not tested device capacities.

PDF reflow is text-only: original images, tables, columns, rich formatting, and original pagination are not preserved. Reading order and paragraph detection are approximate. Scanned pages need OCR elsewhere. RTF reflow can retain supported embedded PNG/JPEG pictures. DOCX is text-only.

Artwork sizing scales text and graphics together, not individual fonts. Larger makes horizontal tiles to avoid cutting off side content. Use the reflowed-text option for larger text without horizontal tiles.

Manual trim applies first. Automatic trim may miss faint content; disable it if needed.

Images are retained only for supported RTF pictures, not PDF/DOCX pictures. RTF picture order follows the source stream; wrapping and caption grouping are not retained.

Prototype: keep originals and verify output. No OCR. PDF artwork reconstruction omits annotations and interactive features; rotated sources are unsupported. Artwork splits can cross lines/tables. RTF parsing is basic: WMF/EMF, binary/linked pictures, and embedded objects unsupported. Standard Latin font coverage only; unsupported characters replaced. Large batches can exhaust memory, especially during ZIP creation. This release has not been run in Safari.
